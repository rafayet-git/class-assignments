Determine the solution set given the coeffient matrix is in row echelon form

**Example:** Unique solution

$$
\left[
\begin{array}{ccc|c}
  1&2&1&1\\
  0&1&1&2\\
  0&0&1&3\\
  0&0&0&0\\
  0&0&0&0 
\end{array}
\right]
\\
0x_1 + 0x_2 + 0x_3 = 0

$$

First three rows in struct upper triangular form

$$
x_3 = 3 \\
x_2 + 3 = 2, x_2 = -1 \\
x_1 +2(-1)+3=1, x_1 = 0 \\
(0, -1, 3)
$$

**Example:** No solution

$$
\left[
\begin{array}{ccc|c}
  1&2&3&4\\
  0&1&1&2\\
  0&0&0&4 
\end{array}
\right]
\\
0x_1 + 0x_2 +0x_3 +0x_4 = 4 \\
\text{Not possible}
$$

<u>Definition:</u> The process of using elementary row operations to transalte a linear system into one whose augmented matrix is in row echelon form  is called **Gaussian elimination**

Reducing a matrix to row echelon:

1. Locate the first column that has a nonzero entry (a pivot). If necessary, use row interchange so that the pivot is in the top row. Divide the row, if necessary, to make the pivot I (or divide at the end)

2. Use the pivot to create 0's below the pivot.

3. Mentally cross off the row and column that enters the pivot + any columns to the left of the pivot, and repeat the prodecure until no rows of columns remain.

Example: Use gaussian elimination to solve:

$$
2x_1 + 3x_2 -x_3 = 7\\
x_2 - 3x_3 = -5 \\
4x_1 +5x_2 - 2x_3 = 10\\


\left[
\begin{array}{ccc|c}
  2&3&-1&7\\
  0&1&-3&-5\\
  4&5&-2&10 
\end{array}
\right] R_3 -2R_1\\

\left[
\begin{array}{ccc|c}
  2&3&-1&7\\
  0&1&-3&-5\\
  0&-1&0&-4 
\end{array}
\right] R_3 + R_2\\

\left[
\begin{array}{ccc|c}
  2&3&-1&7\\
  0&1&-3&-5\\
  0&0&-3&-9
\end{array}
\right] \frac{1}{3}R_3, \frac{1}{2}R_1 \\

\left[
\begin{array}{ccc|c}
  1&3/2&-1/2&7/2\\
  0&1&-3&-5\\
  0&0&1&3
\end{array}
\right]\\

x_3 = 3 \\
x_2 -3(3) = -5, x_2 = 4 \\
x_1 + \frac{3(4)}{2} - \frac{3}{2} = \frac{7}{2}\\
x_1 = -1\\
(-1,4,3)
$$
