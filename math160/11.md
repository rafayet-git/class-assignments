If you switch two rows you must change the sign of the determinant. If two rows are equal, the determinant is 0.

Scalar multiplication property- If a single row of a matrix A is multiplied by a nonzero number a, then the determinant of the resulting matrix is adet(A).

Row addition property - If a multiple fo one row is added to another row of A, the determinant of the resulting matrix is det(A).

If E is obtained by adding a multiple of one row of I to another row, then det(E) = 1 and det(EA) = det(E)det(A) = 1 x det(A) = det(A)
