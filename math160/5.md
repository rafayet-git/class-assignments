### 1.3 Matrix Artithmetic

A matrix is a rectangular array of numbers. If A is a mxn matrix, then 

$$
\left[
\begin{array}{c}
  a_1&a_2&...&a_n \\
  a_{21}&a_{22}&...&a_{2n} \\
  a_{m1}&a_{m2}&...&a_{mn} \\
\end{array}
\right] 
$$

where a_ij denotes the entry in the ith row +  jth col. We write A = a_ij.

Two metrices are equal if they have the same size and same entries

Scalar multiplication: Given alpha, alpha A = alpha (a_ij) = (alpha times a_ij)

$$
2
\left[
\begin{array}{c}
  1&2\\
3&4
\end{array}
\right] = 

\left[
\begin{array}{c}
  2&4\\
6&8
\end{array}
\right]
$$

Matrix addition: Suppose a + b have the same size. We define A+B by A+B (aij) + (bij)

A-B = A+(-1)B

If  A is a mxn matrix + 0 IS THE MXN MATRIX WHOSE ENTRIES ARE ALL 0, THEN A+0 =A

Given A, the matrix (-1)A is its additive inverse: i.e A + (-1)A = A-A = 0

Vectors: The 1xn row matrix $[ a_1 a_2...a_n]$ is  called a row vector. The nx1 column matrix is called a column vector. We use the terminology vector since both are n-tuble , so can be identified with $\mathbb{B}^n$ . $\mathbb{B}^3 = (2,4,-1)$

We identify elements in $\mathbb{B}^n$ with a nx1 column vector :

$$
x \rightharpoonup  \left[
\begin{array}{c}
  b_1\\
b_2\\
...\\
b_n
\end{array}
\right] \in \mathbb{R}^n
$$

Matrix multiplication  + linear systems:

The simplest linear system is the |x| system ax=b. We want to define matrix multiplication so a general linear system is defined. 

We define 

$$
Ax^\rightharpoonup = \left[
\begin{array}{c}
  a_1&a_2&...&a_n
\end{array}
\right]
\left[
\begin{array}{c}
  x_1\\  x_2\\ ... \\ x_n
\end{array}
\right] = \left[
\begin{array}{c}
  a_1x_1&a_2x_2&...&a_nx_n
\end{array}
\right]
$$

So we can write $Ax^\rightharpoonup = b^\rightharpoonup$
